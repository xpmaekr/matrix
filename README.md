# Custom Matrix Terminal Effect

**ASCII-карта Земли из «Матрицы», которая живёт прямо в твоём терминале.**

Кастомный эффект на C++ и ncurses. Работает на любом Linux-дистрибутиве, а на Omarchy ещё и перекрашивается вместе с темой.
Карта Земли нарисована из нулей и единиц, глитчит каждый кадр и парит по центру экрана,
а вокруг идёт лёгкий матричный дождь. Идеально для лока на втором мониторе.

## Фичи

- **Кастомный ASCII-арт** — стилизованная карта Земли из нулей и единиц, как на культовой картинке
- **Классический матричный зелёный** с белыми вспышками на отдельных символах
- **Глитч каждый кадр** — биты хаотично мутируют (`0` ⇄ `1`), картинка выглядит «живой»
- **Динамическое центрирование** — измени размер окна терминала, и арт плавно перестроится, оставшись ровно посередине
- **Матричный дождь на фоне** — тусклые нули и единицы падают за артом
- **Интеграция с темами Omarchy** — цвета читаются из `colors.toml` текущей темы; сменил тему/обои — `matrix` сам перекрасился по `SIGUSR1`, перезапуск не нужен
- Адаптация к светлым/тёмным фонам, работа даже в терминале без 256 цветов
- **Свои цвета** — подсунь свой TOML-файл через переменную окружения

## Требования

| Зависимость | Зачем |
|---|---|
| Любой Linux-дистрибутив | установка через `install.sh` |
| `g++` (или любой C++-компилятор) | компиляция |
| `ncurses` + dev-заголовки | отрисовка в терминале |

Скрипт установки сам определяет пакетный менеджер и ставит зависимости:
`pacman` (Arch), `apt` (Debian/Ubuntu), `dnf` (Fedora), `zypper` (openSUSE),
`apk` (Alpine), `xbps` (Void), `nix-shell` (NixOS).

## Портативная сборка

Нужен бинарь, который запустится на любом дистрибутиве без зависимостей? Собери статически:

```bash
./build-portable.sh   # требует docker;musl + статический ncurses
```

На выходе `build/matrix` — полностью статический ELF (~1.5 МБ): без glibc, libstdc++ и ncurses в зависимостях. Запускается везде: glibc и musl системы, любые версии библиотек.

`install.sh` сам предпочтёт готовый `build/matrix`, если он есть; иначе при наличии Docker соберёт статически, а без Docker — локальным тулчейном.

## Установка

```bash
git clone https://github.com/xpmaekr/matrix.git
cd matrix
./install.sh
```

`install.sh`:

1. определяет пакетный менеджер и ставит `gcc` и `ncurses`, если их нет
2. собирает C++-код в бинарник
3. кладёт его в `/usr/local/bin/matrix`
4. только на Omarchy ставит хук перекраски в `~/.config/omarchy/hooks/theme-set.d/`

После этого `matrix` доступен из любого места.

## Использование

```bash
matrix
```

- **`q`** — выход
- `matrix --colors` — показать, какую тему подхватил эффект и какой цвет взят за основной
- Своя палитра вместо темы Omarchy:

```bash
OMARCHY_MATRIX_COLORS=~/my-colors.toml matrix
```

Формат — обычный `key = "#rrggbb"`. Ключевые поля: `green`, `accent`,
`foreground` / `dark_foreground`, `mode = light|dark`.

## Как это работает

Весь проект — один файл [matrix_theme.cpp](matrix_theme.cpp) на C++ поверх **ncurses**.

- **Отрисовка.** Арт — обычный `std::vector<std::string>`; каждый кадр экран очищается через `erase()` и перерисовывается целиком — ncurses обновляет только изменившиеся ячейки, поэтому CPU почти не напрягается.
- **Глитч.** Каждый кадр случайно выбранные биты инвертируются (`0` → `1` и обратно), часть символов на миг вспыхивает белым.
- **Центрирование.** По `SIGWINCH` ncurses сообщает о новом размере терминала; координаты арта считаются заново как `(cols − width) / 2`, `(rows − height) / 2` — картинка всегда ровно в центре, без перезапуска.
- **Дождь.** Фоновый слой: раз в кадр в случайных колонках вспыхивают тусклые биты (`A_DIM`), создавая лёгкий шум из нулей и единиц за артом.
- **Тема.** При старте (и по хуку `SIGUSR1` при смене темы Omarchy) парсится `colors.toml` и палитра перечитывается на лету.
