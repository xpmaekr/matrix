# matrix 🐱💾

ASCII-кот в стиле «Матрицы» прямо в терминале.

Кот нарисован из ноликов и единиц: символы мутируют, пару раз в секунду
мерцают, а вокруг идёт лёгкий дождь из битов. Идеально для «а чего это у тебя
в терминале?» и для лока на втором мониторе.

**Фишка:** цвета берутся из палитры текущей темы Omarchy (`colors.toml`).
Сменил тему/обои — `matrix` сам перекрасился (хук шлёт ему `SIGUSR1`),
даже перезапускать не надо. На светлом фоне использует тёмные цвета,
на тёмном — классический зелёный. Терминал без 256 цветов? Тоже работает.

## Установка

```bash
git clone https://github.com/xpmaekr/matrix.git
cd matrix
./install.sh
```

`install.sh` соберёт бинарник и установит его в `/usr/local/bin/matrix`,
плюс поставит хук перекраски в `~/.config/omarchy/hooks/theme-set.d/`.

Зависимости: `ncurses`, `gcc` (поставит `sudo pacman -S --needed ncurses gcc`, если их нет — скрипт не ставит, поставь сам или через omarchy, там уже всё есть).

## Запуск

```bash
matrix
```

- `q` — выход
- `matrix --colors` — показать какую тему подхватил и какой цвет взят за основной

## Свои цвета

Не хочешь тему Omarchy — скорми свой toml:

```bash
OMARCHY_MATRIX_COLORS=~/my-colors.toml matrix
```

Формат — обычный `key = "#rrggbb"`. Ключевые: `green`, `accent`,
`foreground` / `dark_foreground`, `mode = light|dark`.

## Омни-структура

| Файл | Зачем |

| `matrix_theme.cpp` | весь исходник, один файл |
| `build.sh` | сборка в `build/matrix` |
| `install.sh` | сборка + установка бинарника и хука |
| `90-matrix-reload` | хук: пингует matrix при смене темы |
